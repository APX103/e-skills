E-Research Skill 使用指南

这个 skill 用来让 agent 承接长任务知识生产：研究、调研、思维实验、计算机科学实验、证据驱动的报告。它不是替代 brainstorming，而是把后续的研究闭环接过去。

Claude Code可自动触发，也可用 /e-research ... 直接调用。
Codex需要在新会话或重启后重新发现 skills；当前对话不会动态刷新。
Hermes已链接到 ~/.hermes/skills/e-research，可用 slash command。
OpenCode / Kimi两者都支持兼容路径，具体见下方附录。

什么时候用

你想做什么 应该用什么 例子
开放式研究、调研、思维实验 e-research 研究一下某种调度算法为什么在长上下文 agent 中更稳。
把模糊想法变成任务契约 brainstorming 一次 先定义研究问题、证据标准、停止条件。
需要写代码、搭环境、跑 benchmark build 实现两个 parser，跑对比实验，输出结果。
验证结果真假、分析失败、设计下一轮实验 think 用 evidence-strength 判断证据够不够。

研究闭环

1. Charter定义研究问题、假设、证据标准、边界和停止条件。
2. Investigate读文件、查资料、看日志、复现实象，先拿高信息密度证据。
3. Experiment只改变一个关键变量，设计最小实验。
4. Review判断成功或失败是否真实，检查证据强度和替代解释。
5. Synthesize输出报告，把 claim 绑定到 evidence，留下可复用知识。

Hermes

安装位置

Hermes 的主 skills 目录是：

~/.hermes/skills/e-research/SKILL.md

如果 Hermes 已经 clone 了这个仓库，直接在仓库根目录运行：

./install.sh update

这会创建或更新这个链接：

~/.hermes/skills/e-research -> /Users/lijialun/work/engineer_skills/skills/e-research

调用方式

Hermes 会把已安装 skill 暴露成 slash command，所以可以直接调用：

/e-research 研究一下 X，先写 Research Charter，再做实验和证据复盘

也可以自然语言触发：

请用 e-research skill 做一个证据驱动的调研：X。

Hermes 很适合这个：它的 skills 系统本身就是渐进加载的 procedural memory，还支持外部 skill 目录。长任务研究时，建议让 Hermes 把产物写到 .agent-log/<timestamp>-research/ 或你指定的项目目录。

Hermes 直接从 GitHub 安装

不想 clone 整个仓库时，可以用 Hermes 的单 skill 安装路径：

hermes skills install APX103/e-skills/skills/e-research

如果先把这个仓库作为 tap 加进去，默认 tap path 是 skills/，然后安装 skill 名：

hermes skills tap add APX103/e-skills
hermes skills install APX103/e-skills/e-research

给 Hermes 自己读的逐步安装和排障文档在仓库里：

docs/hermes-e-research-install.md

Hermes 官方仓库文档说明：skills 默认生活在 ~/.hermes/skills/，每个已安装 skill 会自动成为 slash command，也可以通过自然语言加载；还可配置 external skill directories。

推荐说法

如果你想让 agent 用这个 skill，不要只说“想想 X”。更稳的 prompt 是把产物和边界也说出来：

请使用 e-research skill 研究「X」。
要求：
1. 先写 Research Charter：问题、假设、证据标准、停止条件。
2. 如果需要实验，设计最小实验，只改变一个关键变量。
3. 把事实、假设、解释、未知分开。
4. 最后输出 report.md 和 knowledge.md。

如果是计算机科学研究，可以更具体：

请使用 e-research skill 做一个小型 CS 研究：
比较两种算法在数据集 Y 上的表现。
允许自己搭环境、写 benchmark、跑实验。
每轮实验后检查 evidence-strength，再决定是否继续。
